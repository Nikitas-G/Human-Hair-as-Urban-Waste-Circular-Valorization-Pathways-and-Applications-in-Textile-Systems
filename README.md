Human Hair as Urban Waste: Circular Valorization Pathways
Official code repository for the research paper: "Human Hair as Urban Waste: Circular Valorization Pathways and Applications in Textile Systems".

Overview
This repository contains the algorithmic frameworks developed to validate human hair as a high-performance circular feedstock. 
The project reconciles material science benchmarks with digital sustainability through two primary computational tools:
1. CCF Logic and Sustainability Threshold Calculator
2. CCF Sensitivity Analysis: Models the "Sustainability Ceiling" where algorithmic complexity negates physical CO2 savings.
3. Swarm Intelligence Logistical Optimizer: A framework for decentralized urban waste collection using SI algorithms (Bat Algorithm, Fast Bacterial Swarming).

Algorithms Included

1. Computational Carbon Footprint (CCF) ModelThis script implements the non-linear entropy function used to calculate the digital carbon footprint of logistics. 
It utilizes a superfactorial (sf) operator to penalize over-complex ICT configurations.

Key Equation:
CO2 = H(Np)*sf(Ni)*math.prod(hk)*Ph*η*er

2. Swarm Intelligence (SI) Optimization
Implementation of hybrid SI models for optimizing the collection of human hair waste (EWC 20 03 01) from decentralized urban nodes.
